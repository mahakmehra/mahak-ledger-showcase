Ledger Agent

A plain-English question-answering service for the Acme Appliances order ledger.

What it does

Takes a question about revenue, refunds, products or customers and returns the answer as JSON. It was built for an API with no documentation, so the data's quirks had to be found and handled:

  • Duplicate order ids: the row with the latest updated_at is current.
  • Only paid orders count as revenue.
  • USD, EUR and INR amounts are converted to USD using the live rates endpoint, rounded to the cent.
  • Business dates use the Asia/Kolkata timezone.

Try it

curl -X POST https://mahak-ledger-agent.vercel.app/ \
  -H 'content-type: application/json' \
  -d '{"question":"How much did North earn in April 2026, in US dollars?"}'
# {"answer": 28854.62}

Built with

Python standard library, deployed on Vercel.
